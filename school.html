School

I'm taking CIS 132, a course on building web pages with HTML and CSS. Everything on this site was written by hand in a text editor, checked with the W3C validators, and published with GitHub Pages.

What this project taught me

For this phase I rebuilt my pages with a centered layout, a styled horizontal navigation bar, and two fluid columns that resize with the browser window. All of the styling lives in one external style sheet, so a change there updates every page at once.

Project phases

  1. Page structure with HTML5
  2. External style sheet
  3. Centered two column layout
